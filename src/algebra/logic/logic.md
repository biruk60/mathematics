# Logic
## መእተዊ / Introduction
- ሎጂክ ዝብል ቃል፣ ሎጎስ ካብ ዝብል ናይ ግሪኽ ቃል ዝመፀ ኮይኑ፡ ርትዒ ወይ ዘተ ወይ መጎት ተባሂሉ ክትርጎም ይኽእል እዩ።
ሎጎስ = ርትዒ / መጎት

- ከመይ ከም ንሓስብን ከምነስትውዕልን ፈለማ መፅናዕቲ ዘገበሩ፣ ጥንታዎት ግሪካውያን እዮም ዝብል እምነት ኣሎ።  ነዞም ብጥንታዎት ግሪካውያን ዝተረኸቡ ናይ ኣተሓሳስባ መትከላት ስርዓትን ቕጥዒን ዘትሓዞም፣ እቲ ውሩይ ግሪካዊ ፈላስፋ ኣሪስቶትል (384-322 B.C) እዩ።  ናይ ኣርስቶትል ዓይነት ስነ መጎት፣ እሱ ካብ ዝፈለሞ ኣትሒዙ እስካብ ሕዚ ኣብ ሙህሮን ኣብ ተግባርን ዘካየድ ዘሎ ባህላዊ ስነ መጎት እዩ።  

- መፅናዕቲ ዘመናዊ ስነ መጎት ዝኾነ እቲ ትእምርቲዊ ስነ-መጐት፣  ኣብ ስራሕቲ ጀርመናዊ  ክኢላ ስነ ሓሳብ ላይብነት (1647-1716) ዝሰረተ እንተኾነ እኳ፣ ቀመራት ዘመናዊ ትእምርቲን ኣልጄብራን፣ ብስርዓት ኣብ ስነ መጎት ዝተተግበሩ፣ ኣብ ስርሓት እንግሊዛዊ ክኢላ ስነ ሓሳብ ጆርጅ ቡል (1815-1864) እዩም።

- ካብ ትንተና ቡል ጀሚሩ፣ መፅናዕቲ ስነ፡መጐት፣ ብዝተቐላጠፈ ናህሪ ማዕቢሉ እዩ።

- ዝኾነ ፀገም ንምፍታሕ እንትፍትን ወይ ድማ ኣብ ዝኾነ ዘተ እንዝቲ፣ ስነ መጎታዊ ርትዒ ኣብ ዝበሃል ናይ ኣእምሮ ንጥፈት ኢኻ ትዋፈር ዘለኻ። እዙይ ኣእምሮኣዊ ንጥፈት ድማ፣ መብዛሕትኡ ግዜ፣ ሙሉእ ሓሳብ ብዝሓዙ ሓረጋት እዩ ዝግለፅ። ኣብዚ ቪድዮ፣ ኣቃልቦና ኣብ መፅናዕቲ እዞም ሙሉእ ሓሳብ ዝሓዙ ሓረጋት እዩ ክኾን።
## ሓሳብ / Proposition
- ኣብ መዓልታዊ ዘረባና እንረኽቦም ሓረጋት፣ ኹላቶም፣ ሙሉእ ሓሳብ ዝሓዙ ሓረጋት ኣይኾኑን እዮም። ገሊኦም ሕቶታት፣ ገሊኦም ትእዛዛት፣ ገሊኦም ትምኒታትን ልመናታትን ዝገልፁ እዮም። ስነ መጎት፣ ብኡ ኣቢሉ እውን ሒሳብ ግን፣ ሙሉእ ሓሳብ ኣብ ዝገልፁ ሓረጋት ጥራሕ እዩ ዝግደስ። ንኣብነት፣ ነዞም ዝስዕቡ ኣርባዕተ ሓረገት እንተርኢና፣ 


1. እዙይ ሕብሪ፣ ፃዕዳ እዩ።
2. ጠጠው በል!
3. ርሑስ ጋማ!
4. ናበይ ትኸይድ ኣለኻ?

- እቲ ኣብ ቁፅሪ ሓደ ዘሎ ሓረግ ጥራሕ እዩ ሙሉእ ሓሳብ ዝገልፅ። እቶም ዝቐረዩ ሓረጋት፣ ትእዛዝ፣ ትምኒት፣ ሕቶ ዝገልፁ እዮም። ብኻልእ ኣዘራርባ፣ እቲ ሓረግ ሓቂ ክኸውን ከሎ፡ ሓቂዊ ዋጋ T፡ ሓሶት ምስ ዝኸውን ድማ ሓቂዊ ዋጋ F ክንምድበሉ ንኽእል፣ ነቲ ኣብ ቑፅሪ ሓደ ዘሎ ሓረግ ጥራሕ እዩ።


- መብርሂ: ሓሳብ (proposition)፣ ዝኾነ ትርጉም ዘለዎ፣ ንፁርን ዘየሻሚን ሓረግ እዩ። እቲ ሓሳብ፣ ወይ ሓቂ ወይ ሓሶት ክኾን ይኽእል እዪ። ኣብ ሓደ እዋን ግን፣ ሓቂን ሓሶትን ክኾን ኣይኽእልን።

    - ንኣብነት "ሓሙሽተ ካብ ሽዱሽተ ይንእስ (5 < 6)" ዝብል ሓረግ ሓሳብ (proposition) እዩ። ሓቀኛ ሓሳብ ስለ ዝኾነ ድማ፣ ሓቂዊ ዋጋኡ T እዩ።
    - "ክልተ ክድመር ሓሙሽተ ማዕረ ሽዱሽተ (2 + 5 = 6)" ዝብል ሓረግ፣ ሓሶት ሓሳብ ስለ ዝኾነ፣ ሓቂዊ ዋጋኡ F እዩ። 

- መብርሂ: ኽፉት ሓሳብ(open proposition)፣ ሓደ ወይ ልዕሊ ሓደ ተለዋወጥቲ ወይ ተውላጠ-ስማት ዝሓዘ ሓረግ ኮይኑ፣ ሕድ ሕድ ተለዋዋጢ ወይ ተውላጠ-ስም ብፍሉይ ዋጋ ወይ ብውልቀ-ሰብ ምስ ዝትካእ፣ ሓሳብ ይኸውን። 
  - "x ክቕነስ ሰለስተ ማዕረ ሽዱሽተ (x -3 = 6)" ን "እሱ ፓይለት እዩ" ዝብሉ ኽፉታት ሓሳባት፡ "x" ብቑፅሪ ምስ ዝትካእ፡ "እሱ" ዝብል ተውላጠ ስም ድማ ብሰብ ምስ ዝትካእ፡ መግለጺ ይኾኑ። ብኻልእ ኣገላልፃ፣ ኹፍት ሓረግ ሓቃዊ ዋጋ ክንምድበሉ ንኽእል፣ ናብ ሙሉእ ሓሳብ ምስ ተቐይረ ጥራሕ እዩ። 

## ዓይነታት ሓሳባት / Types of Propositions
- መብርሂ: simple proposition (ቐሊል ሓሳብ)፣ ከም and (ከምኡ እውን) or (ወይ) not (ኣይኰነን) ፡ ወዘተ... ዝኣመሰሉ ጠመርቲ ቃላት ዘይብሉ፣ ሓደ ሙሉእ ሓሳብ ዘመሓላልፍ ሓረግ እዩ።
-  ንኣብነት: 
  - ሀ. መቐለ ርእሰ ከተማ ትግራይ እያ።
  - ለ. ወለደ ኣብርሃ ንጉስ፣ ብሉፅ ፖለቲከኛ ትግራይ እዩ።
- ነዞም ቀለልቲ ሓሳባት፣ p,q, r, s ወዘተ... ብዝብሉ ናይ እንግሊዝኛ ፊደላት ምስያም ንቡር እዩ። 
- 
- መብርሂ: ክልተ ወይ ልዕሊኡ ቀለልቲ ሓሳባት ብመልክዕ ሓደ ሓረግ እንትግለፁ፣ compound (ውሁድ) ሓሳብ ይፈጥሩ። 
-  ንኣብነት 
  - ናይ ሓደ ስኵር ሩት ሓደ (√1 = 1) ከምኡውን ሰለስተ ካብ ኣርባዕት ይንእስ (3 < 4). 
  - ድሕሪ ሰሉስ ዘሎ መዓልቲ ረቡዕ or ክልተ ክድመር ክልተ ማዕረ ኣርባዕት (2 + 2 = 4).
- ኣብ ሓደ ውሁድ ሓሳብ ዝርከቡ ውልቀ-ሓሳባት፡ ባእታ ሓሳባት ይበሃሉ። 
- ናይ ሓደ ውሁድ ሓሳብ ሓቃዊ ዋጋ፣ ካብቶም ዝተሰረተሎም ሕድ ሕድ ባእታ ሓሳብታ ሓቃዊ ዋጋታት ዝምንጭው እዩ። ናይ ሓደ ውሁድ ሓሳብ ሓቃዊ ዋጋ ዝህብ ሰሌዳ ድማ ሓቃዊ ሰደቓ (truth table) ይባሃል።
- ቀልቢ ዘድልዮ: ሓደ ውሁድ ሓሳብ፣ ቑፅሮም n ዝኾኑ ብእታ ሓሳብት እንተልዮሙዎ፣ ሓቃዊ ዋጋ ናይ እዚ ውሁድ ሓሳብ $2^n$ ስነ መጎታዊ ተኽእሎታት (logical possiblities) ኣለዎም።

## መጥመርቲ / Connectives
- ሓደ ውሁድ ሓሳብ ንምፍጣር፣ ቀለልቲ ዝኾኑ ሕሳባት ብሓደ ክንፅምብሮም ኣለና። እዙይ ንምፍፃም ድማ፣ ሓሙሽተ መሰረታዊ ስነ-መጎታዊ መጥመርቲ ኣለውና። እሳቶም ድማ:
 - ኣንፃር / Negation 
 - መስተፃምር / Conjunction
 - ፍልያ / Disjunction
 - ዝተኣመተ / Implication
 - ድርብ ዝተኣመተ / Bi-implication
 
 እስኪ ሓደ ብሓደ ንዳህስሶም....
- ### ኣንፃር / Negation
  - መብርሂ: p ዝባሃል ሓሳብ እንተልዩ፣ ¬p ናይ p ኣንፃር ምልክት እዩ። 'p ኣይኾነን እዩ' ዝብል ሓሳብ ኢልና ንገልፆ። 
  - ንኣብነት: 
      - P = "እቲ ቤተ መፃሕፍቲ ሕዚ ኽፉት እዩ።" ዝብል እንተኾይኑ፣ ናይ እዙይ ሓሳብ ኣንፃር ድማ ¬P = "እቲ ቤተ መፃሕፍቲ ሕዚ ኽፉት ኣይኾነን" ዝብል እዩ።  
      - ናይ p and ¬p ርክብ፣ ብዝስዕብ ናይ ሓቂ ሰደቓ ክግለፅ ይኽእል እዩ። 
- ### መስተፃምር / Conjunction
  - መብርሂ: pን qን ዝባሃሉ ክልተ ሓሳባት እንተልዮም፣ pን qን ክልቲኦም ሓቂ እንተኾይኖም ጥራሕ እዩ፣ ናይ pን qን መስተፃምር / conjunction ሓቂ ዝኾን። ምልክቱ ድማ፣ p ∧ q እዩ።  
  - ናይ p ∧ q ስነ-መጎታዊ ተኽእሎታት፣ ብዝስዕብ ናይ ሓቂ ሰደቓ ክግለፁ ይኽእሉ እዮም። 

- ### ፍልያ / Disjunction 
  -መብርሂ: pን qን ዝባሃሉ ክልተ ሓሳባት እንተልዮም፣ pን qን ክልቲኦም ሓሶት እንተኾይኖም ጥራሕ እዩ፣ ናይ pን qን ፍልያ / disjunction ሓሶት ዝኾን። ምልክቱ ድማ፣ p ∨ q እዩ።
  - ናይ p ∨ q ስነ-መጎታዊ ተኽእሎታት፣ ብዝስዕብ ናይ ሓቂ ሰደቓ ክግለፁ ይኽእሉ እዮም።   

- ### ዝተኣመተ / Implication
  - መብርሂ: pን qን ዝባሃሉ ክልተ ሓሳባት እንተልዮም፣ p ሓቂ ን q ሓሶት ን እንተኾይኖም ጥራሕ እዩ፣ ናይ pን qን ዝተኣመተ / Implication ሓሶት ዝኾን። ምልክቱ ድማ፣ p → q እዩ።
  - ናይ p → q ስነ-መጎታዊ ተኽእሎታት፣ ብዝስዕብ ናይ ሓቂ ሰደቓ ክግለፁ ይኽእሉ እዮም።      
  - ኣብ p → q, ሓሳብ p ቅድመ ፍጻመ (antecedent) እንትባሃል፣ ሓሳብ q ድማ ዝስዕብ (consequent) ይባሃል።
  - ቀልቢ ዘድልዮ: p → q ማለት p ናይ q ሰኒኪ ወይ ድማ q ናይ p ሳዕቤን እዮ ማለት ኣይኮነን። "p ሓቂ ኣብ ዝኾነሉ እዋን q እውን ሓቂ እዩ። p ሓሶት ኣብ ዝኾነሉ እዋን ድማ q እውን ሓሶት እዩ።" ካብ ምባል ንላዕሊ፣ እቲ ኩነታዊ ሓሳብ፣ ኣብ መንጎ pን qን ዝኾነ ስነ-መጎታዊ ምትእስሳር ንኽህሉ ግዲ ኣይብልን።
    - ንኣብነት:   ሓሳብ p ክልተ ካብ ኔገቲቭ ክልተ ይንእስ ዝብል ተኾይኑ፣ q ድማ፣ ኣርባዕተ ካብ ሓደ ይዓቢ ዝብል ተኾይኑ፣ ዋላ እኳ ናይ p ሓቃዊ ዋጋ F ናይ q ሓቃዊ ዋጋ ድማ T እንተኾነን፣ ኣብ pን qን ምንም ዓይነት ናይ ስንክን-ሳዕቤንን ርክብ እንተዘይሃለወን፣ ናይ p → q ሓቃዊ ዋጋ T እዩ።  ብኻልእ ኣባህላ፣ pን qን ብ implication ስለ ዝተጣመሩ ጥራሕ፣ ካብ ሓሳብ p ተበጊስና ስለ ሓቅነት ሓሳብ q መደምደምታ ክንበፅሕ ኣይንኽእልን። 

  - ቀልቢ ዘድልዮ:  p → q implication ተኾይኑ , then 
    1. ብ q → p ዝግለፅ ናይ pን qን ርክብ converse ይባሃል። 
    2. ብ ¬p → ¬q ዝግለፅ ናይ pን qን ርክብ inverse ይባሃል። 
    3. ብ ¬q → ¬p ዝግለፅ ናይ pን qን ርክብ ድማ፣ contrapositive ይባሃል።

 - ### ድርብ ዝተኣመተ / Bi-Implication
   - መብርሂ: pን qን ዝባሃሉ ክልተ ሓሳባት እንተልዮም፣ pን qን ክልቲኦም ሓቂ እንተኾይኖም ወይ ክልቲኦም ሓሶት እንተኾይኖም ጥራሕ እዩ፣ ናይ pን qን ድርብ ዝተኣመተ / bi-implication ሓቂ ዝኾን። ምልክቱ ድማ፣ p ↔ q እዩ።
   - ናይ p ↔ q ስነ-መጎታዊ ተኽእሎታት፣ ብዝስዕብ ናይ ሓቂ ሰደቓ ክግለፁ ይኽእሉ እዮም። 
   
- ## ህውላለ ወ ግርጭት / Tautology and Contradiction
  - መብርሂ: ዋጋ ሓቃዊነት ዝተደረኸሎም ቀለልቲ ሓሳባት ብዝየገደስ፣ ሓቃዊ ዋጋ ሓደ ውህድ ሓሳብ ኩሉ ሻዕ T እንተኾይኑ፣ እዙይ ሓሳብ ህውላለ / tautology ይባሃል። ምልክቱ ድማ፣ t እዮ። 
  - ንናይ p ∨ ¬p ውሁድ ሓሳብ ናይ ሓቂ ሰደቕ እንተርኢና፣ ሓቃዊ ዋጋታት ናይ pን ¬pን ብዝየገደስ፣ ሓቃዊ ዋግኡ ኩሉ ሻዕ T እዩ።
  - መብርሂ: ዋጋ ሓቃዊነት ዝተደረኸሎም ቀለልቲ ሓሳባት ብዝየገደስ፣ ሓቃዊ ዋጋ ሓደ ውህድ ሓሳብ ኩሉ ሻዕ F እንተኾይኑ፣ እዙይ ሓሳብ ግርጭት / contradiction ይባሃል። ምልክቱ ድማ፣ c እዮ።
  - ንናይ p ∧ ¬p ውሁድ ሓሳብ ናይ ሓቂ ሰደቕ እንተርኢና፣ ሓቃዊ ዋጋታት ናይ pን ¬pን ብዝየገደስ፣ ሓቃዊ ዋግኡ ኩሉ ሻዕ F እዩ። 
 

## ስነ-መጐታዊ መዓርነት / Logical Equivalence
- መብርሂ: ክልተ ሓደ ዓይነት ባእታ ሓሳብ ዘጠቓልሉ ሓሳባት ተመሳሳሊ ናይ ሓቂ ሰደቓታት እንተሃልይዎም፣ ስነ-መጐታዊ ማዕረ እዮም ይበሃል። ናይ እዙይ ስነ-መጐታዊ መዓርነት ምልክት ድማ ≡ እዩ።

- p፣ q፣ r፣ ዝባሃሉ ሓሳባት እንተወሲድና፣ እዞም ዝስዕቡ ዓሰርተ ሓደ ስነ-መጎታዊ መዓርነታት፣ መሰረታዊ ናይ ኣልጀብራ ሕግታት እዮም። ሓቅነቶም ድማ፣ ብናይ ሓቂ ሰደቕ፣ ሓደ በሓደ ክነረጋግፆም ኢና።    
  - Commutative law: p ∧ q  ≡ q ∧ p
  - Associative law: (p ∧ q) ∧ r ≡ p ∧ (q ∧ r)
  - Distributive law: p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)    
  - Identity law: p ∧ t ≡ p    
  - Negation law: p ∧ ¬p ≡ c
  - Double Negation law: ¬(¬p) ≡ p 
  - Idempotent law:  p ∧ p ≡ p  
  - De Morgan's law: ¬(p ∧ q) ≡ ¬p ∨ ¬q   
  - Universal bound law: p ∨ t ≡ t
  - Absorption law: p ∧ (p ∨ q) ≡ p
  - Negations of t and c:  ¬t ≡ c
